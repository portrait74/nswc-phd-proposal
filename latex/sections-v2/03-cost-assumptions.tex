\section{Cost Assumptions}

The draft budget will be developed using the following planning assumptions:

\begin{itemize}
  \item The proposed period of performance is assumed to be 12 to 18 months unless otherwise directed.
  \item The effort is expected to be university-led, with CSULB serving as the primary proposing institution.
  \item The technical effort will emphasize simulation-based research, algorithm development, validation, and reporting.
  \item Any use of controlled data, government-furnished information, export-controlled material, or classified resources will require separate review and approval before inclusion in the work plan or budget.
  \item Final labor categories, fringe rates, indirect rates, and institutional budget format will be confirmed with CSULB sponsored programs.
\end{itemize}
