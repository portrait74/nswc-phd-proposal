\section{Technical Objectives}

The objective of this effort is to develop a reinforcement learning-augmented guidance framework that improves the robustness and computational feasibility of hypersonic glide vehicle guidance in dynamic threat environments.

\begin{enumerate}
  \item Advance predictive guidance methods for hypersonic glide vehicles facing continuously updated Predicted Intercept Points.
  \item Develop a multi-model NPCG ensemble that captures atmospheric, aerodynamic, vehicle, and threat-model uncertainty.
  \item Train an RL guidance agent using physics-informed trajectory and guidance data generated by the multi-model NPCG ensemble.
  \item Evaluate whether the RL agent can preserve terminal targeting accuracy and PIP clearance while reducing real-time predictor-corrector computation.
  \item Establish a simulation-based validation framework for future NSWC PHD hypersonic GNC research.
\end{enumerate}
