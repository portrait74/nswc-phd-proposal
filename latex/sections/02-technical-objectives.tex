\section{Technical Objectives}

The objective of this effort is to develop a reinforcement learning-augmented guidance framework in which NPCG-generated ideal guidance under atmospheric, weather-driven, aerodynamic, and vehicle-model uncertainty is used to train an adaptive RL guidance agent.

\begin{enumerate}
  \item Advance predictive guidance methods for hypersonic glide vehicles facing continuously updated Predicted Intercept Points.
  \item Develop a multi-model NPCG ensemble that captures atmospheric, weather-driven, aerodynamic, vehicle, and threat-model uncertainty.
  \item Use the multi-model NPCG ensemble to generate ideal or expert trajectory, correction, and maneuver guidance data across uncertain flight conditions.
  \item Train an RL guidance agent using the NPCG-generated physics-informed guidance data and simulated sensor-informed vehicle states.
  \item Evaluate whether the RL agent can preserve terminal targeting accuracy and PIP clearance while reducing real-time predictor-corrector computation.
  \item Establish a simulation-based validation framework for future NSWC PHD hypersonic GNC research.
\end{enumerate}
